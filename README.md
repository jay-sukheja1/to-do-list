# Simple To-Do List App

A responsive, lightweight, and modern web-based To-Do List application. This project is built using pure HTML, CSS, and Vanilla JavaScript with local storage persistence.

## Features

- **Add Tasks**: Quickly type a task and add it to your list.
- **Check/Uncheck Tasks**: Click on any task item to toggle its completion state (visualized with a checkmark and strike-through styling).
- **Delete Tasks**: Remove individual tasks from your list by clicking the delete (`×`) icon.
- **Persistent Data**: Tasks are automatically saved to the browser's `localStorage`. Your list remains intact even after closing or refreshing the tab/browser.
- **Responsive Design**: Designed with a clean, premium user interface that looks great on mobile, tablet, and desktop viewports.
